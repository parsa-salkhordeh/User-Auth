آموزش فرانت اند

HTML

HTML زبان نشانه‌گذاری صفحات وب است. با استفاده از آن ساختار اصلی صفحات را ایجاد می‌کنیم. عناصری مانند عنوان، پاراگراف، تصویر و لینک با HTML ساخته می‌شوند. HTML مشخص می‌کند هر بخش از صفحه چه محتوایی دارد. یادگیری آن اولین قدم برای ورود به دنیای فرانت‌اند است.

CSS

CSS برای طراحی و زیباسازی صفحات وب استفاده می‌شود. با آن می‌توان رنگ، فونت، اندازه و فاصله عناصر را تغییر داد. همچنین امکان ایجاد چیدمان‌های مختلف برای صفحه وجود دارد. با استفاده از طراحی واکنش‌گرا، صفحات در موبایل و کامپیوتر به‌خوبی نمایش داده می‌شوند. CSS ظاهر صفحات HTML را جذاب و منظم می‌کند.

JavaScript

جاوااسکریپت یک زبان برنامه‌نویسی برای ایجاد تعامل در صفحات وب است. با آن می‌توان به رویدادهایی مانند کلیک کاربر پاسخ داد. امکان تغییر محتوا و ویژگی‌های عناصر صفحه وجود دارد. همچنین می‌توان اطلاعات را از سرور دریافت و نمایش داد. جاوااسکریپت صفحات وب را پویا و تعاملی می‌کند.
