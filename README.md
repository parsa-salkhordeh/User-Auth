# 🔐 سیستم ثبت‌ نام و ورود کاربران

یک پروژه کاربردی با استفاده از **HTML، CSS و JavaScript** با هدف تمرین اعتبارسنجی فرم‌ها، مدیریت کاربران، احراز هویت اولیه و محافظت از صفحات.

این پروژه شامل صفحات ثبت‌نام، ورود و پروفایل کاربران است و با استفاده از JSON Server اطلاعات کاربران را مدیریت می‌کند.

## ✨ امکانات پروژه

*  **ثبت‌ نام کاربران:** دریافت اطلاعات کاربران و اعتبارسنجی فرم ثبت‌نام.
*  **ورود کاربران:** بررسی اطلاعات ورود و احراز هویت اولیه.
*  **صفحه پروفایل:** نمایش اطلاعات کاربر واردشده.
*  **محافظت از صفحات (Route Protection):** جلوگیری از دسترسی عادی کاربران واردنشده به صفحات محافظت‌شده.
*  **تغییر رمز عبور:** امکان تغییر رمز عبور از طریق صفحه پروفایل.
*  **Local Storage:** ذخیره و بازیابی اطلاعات کاربر در مرورگر.
*  **JSON Server:** شبیه‌سازی بک‌اند و مدیریت اطلاعات کاربران از طریق API.
*  **اعتبارسنجی فرم‌ها:** بررسی صحت اطلاعات واردشده پیش از پردازش.
*  **خروج از حساب کاربری:** پاک‌کردن اطلاعات ذخیره‌شده کاربر و انتقال به صفحه ورود.
*  **پیام‌های اطلاع‌رسانی:** نمایش پیام‌های موفقیت و خطا با استفاده از Toastify و Dialog System

## 🛠️ تکنولوژی‌های استفاده‌شده

* HTML5
* CSS3
* JavaScript (ES6+)
* JSON Server
* Fetch API
* Local Storage
* Toastify JS


## 🚀 نحوه اجرای پروژه

### ۱. دریافت پروژه

```bash
git clone YOUR_REPOSITORY_URL
```

### ۲. نصب وابستگی‌ها

ابتدا وارد پوشه پروژه شوید و وابستگی‌های موردنیاز را نصب کنید:

```bash
npm install
```

اگر JSON Server در پروژه نصب نشده است:

```bash
npm install -D json-server
```

### ۳. اجرای JSON Server

```bash
npx json-server db.json
```

مطمئن شوید آدرس API در فایل‌های JavaScript با آدرس سرور اجراشده مطابقت دارد.

### ۴. اجرای پروژه

پروژه را در VS Code باز کنید و با استفاده از افزونه Live Server اجرا کنید.
